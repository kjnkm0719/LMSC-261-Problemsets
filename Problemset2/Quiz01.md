# Quiz 01

## 1. What is a repository when using Git and GitHub?
A project containing files and their version history.

## 2. What does `commit` mean when using Git?
Capture a snapshot of the project's staged changes.

## 3. What does `pull` do when using Git?
Downloads changes from a remote repository and updates the local repository.

## 4. Which filename does GitHub automatically display as the main Markdown document for a repository?
`README.md`

## 5. What is the binary number `10000011` in decimal?
131

128 + 2 + 1 = 131

## 6. What does the ASCII sequence `76 77 83 67 45 50 54 49` represent?
LMSC-261

## 7. What does it mean that Python is an interpreted programming language?
Python code can be run without manually compiling it first.

## 8. What is sequential execution?
Instructions execute in the order they appear in the program.

## 9. What is a condition in programming?
An expression that can determine whether an action should occur.

## 10. Which statement correctly assigns the value `26` to a variable named `abc` in Python?
`abc = 26`

## 11. What does the following Python statement do?

`counter += 1`

Increases `counter` by 1.

## 12. What does each operator do in Python?

`==` : Checks if two values are equal.

`=` : Assigns a value to a variable.

`-=` : Subtracts a value from a variable and assigns the new value back to it.

## 13. What is important about the indentation in the following code?

`if x < y:`
`    print("x is less than y")`

It indicates that the `print()` statement belongs to the `if` block.

## 14. What is a `while` loop?
A loop that repeats as long as a condition is true.

## 15. What is a `for` loop?
A loop that repeats over a sequence of values.

## 16. What values are produced by a) `range(5)` and b) `range(5,10)`?
a) `0, 1, 2, 3, 4`

b) `5, 6, 7, 8, 9`

## 17. What does the `%` operator do in Python?
It returns the remainder after division.

## 18. Which statement correctly creates a single line comment in Python?
`# This is a comment`

## 19. What is Conda used for in this class?
Managing Python environments and packages.

## 20. What does `if __name__ == "__main__":` check in Python?
Whether the current Python file is being run directly as the main program.
